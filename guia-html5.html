02

¿Qué es HTML5?

HTML significa HyperText Markup Language — el lenguaje de marcado que define la estructura y el contenido de cualquier página web. La versión 5 es el estándar actual desde 2014.

Piénsalo así: si una página web fuera una casa, HTML sería la estructura arquitectónica — paredes, puertas, ventanas. CSS sería la pintura y decoración, y JavaScript el sistema eléctrico.

¿Cómo funciona?

Un archivo HTML es un documento de texto plano que el navegador interpreta y convierte en la página visual que ves. No necesitas instalar nada especial — solo un editor de texto y un navegador.

💡 Herramientas recomendadas

Usa Visual Studio Code (gratuito) como editor y Google Chrome o Firefox como navegador para ver los resultados en tiempo real.

Extensión del archivo

Los archivos HTML tienen la extensión .html. El archivo principal de un sitio web siempre se llama index.html.

03

Estructura Base de un Documento

Todo archivo HTML5 válido debe tener esta estructura mínima. Es el "esqueleto" que el navegador espera encontrar:

HTML
<!-- index.html — Estructura base de HTML5 -->

<!DOCTYPE html>
<html lang="es">

  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mi Primera Página</title>
  </head>

  <body>

    <!-- Todo el contenido visible va aquí -->
    <h1>¡Hola, mundo!</h1>

  </body>

</html>

Explicación de cada parte

  • <!DOCTYPE html> — Declara que el documento es HTML5. Siempre va en la primera línea.
  • <html lang="es"> — Elemento raíz que envuelve todo. El atributo lang indica el idioma.
  • <head> — Información para el navegador, no visible en pantalla. Aquí van el título, estilos CSS, metadatos.
  • <meta charset="UTF-8"> — Permite mostrar acentos, ñ y caracteres especiales correctamente.
  • <meta viewport> — Hace la página responsive en dispositivos móviles.
  • <title> — El texto que aparece en la pestaña del navegador.
  • <body> — Todo el contenido visible de la página va dentro de este elemento.
💡 Tip de práctica

Crea una carpeta llamada mi-sitio, dentro crea un archivo index.html, pega esta estructura y ábrela con el navegador. ¡Ya tienes tu primera página web!

04

Etiquetas Esenciales

Las etiquetas (o tags) son los bloques de construcción de HTML. La mayoría tienen apertura y cierre: <etiqueta>contenido</etiqueta>. Algunas son auto-cerrantes: <img>, <br>, <hr>.

Etiqueta
Función
<h1> – <h6>
Encabezados del más importante (h1) al menos (h6)
<p>
Párrafo de texto
<a>
Enlace / hipervínculo
<img>
Imagen (auto-cerrante)
<ul> / <ol>
Lista no ordenada / ordenada
<li>
Elemento de lista
<div>
Contenedor genérico en bloque
<span>
Contenedor genérico en línea
<br>
Salto de línea (auto-cerrante)
<hr>
Línea horizontal divisora
05

Atributos

Los atributos añaden información o comportamiento a las etiquetas. Siempre van dentro de la etiqueta de apertura con el formato nombre="valor".

HTML — Ejemplos de Atributos
<!-- id: identificador único en la página -->
<section id="sobre-mi">...</section>

<!-- class: nombre para agrupar y aplicar estilos CSS -->
<p class="destacado">Texto importante</p>

<!-- href: destino del enlace -->
<a href="https://google.com">Ir a Google</a>

<!-- src y alt: fuente de imagen y texto alternativo -->
<img src="foto.jpg" alt="Descripción de la imagen">

<!-- target: cómo abrir el enlace -->
<a href="page.html" target="_blank">Abre en nueva pestaña</a>
⚠️ Importante

El atributo alt en las imágenes es obligatorio para accesibilidad. Describe lo que muestra la imagen para usuarios con lectores de pantalla.

06

Texto y Tipografía

HTML ofrece varias etiquetas para dar significado semántico al texto, no solo estilo visual:

HTML — Formato de Texto
<!-- Encabezados (de mayor a menor importancia) -->
<h1>Título Principal de la Página</h1>
<h2>Subtítulo de Sección</h2>
<h3>Subtítulo de Sub-sección</h3>

<!-- Párrafo normal -->
<p>Este es un párrafo con texto normal.</p>

<!-- Énfasis semántico -->
<p>Texto con <strong>negrita importante</strong>
   y texto con <em>énfasis en cursiva</em>.</p>

<!-- Cita en bloque -->
<blockquote>
  "La simplicidad es la máxima sofisticación."
</blockquote>

<!-- Código -->
<p>Usa la etiqueta <code><p></code> para párrafos.</p>
💡 Regla de oro

Usa <strong> para contenido importante (semántico) y no solo para hacer texto en negrita. Para estilo puro, usa CSS.

07

Listas

Hay dos tipos principales de listas en HTML. Ambas usan <li> para cada elemento:

HTML — Listas
<!-- Lista NO ordenada (viñetas) -->
<ul>
  <li>HTML — estructura</li>
  <li>CSS — estilos</li>
  <li>JavaScript — interactividad</li>
</ul>

<!-- Lista ORDENADA (números) -->
<ol>
  <li>Instalar VS Code</li>
  <li>Crear index.html</li>
  <li>Escribir código HTML</li>
  <li>Abrir en el navegador</li>
</ol>

<!-- Lista de definición -->
<dl>
  <dt>HTML</dt>
  <dd>HyperText Markup Language</dd>
  <dt>CSS</dt>
  <dd>Cascading Style Sheets</dd>
</dl>
08

Enlaces e Imágenes

Tipos de enlaces

HTML — Etiqueta <a>
<!-- Enlace externo -->
<a href="https://mozilla.org" target="_blank">
  Visitar MDN Web Docs
</a>

<!-- Enlace interno (otra página del mismo sitio) -->
<a href="contacto.html">Ir a Contacto</a>

<!-- Ancla: saltar a una sección de la misma página -->
<a href="#sobre-mi">Ver Sobre Mí</a>

<!-- El destino del ancla debe tener ese id -->
<section id="sobre-mi">
  <h2>Sobre Mí</h2>
</section>

<!-- Enlace de correo -->
<a href="mailto:hola@ejemplo.com">Enviar email</a>

Imágenes

HTML — Etiqueta <img>
<!-- Imagen local (misma carpeta) -->
<img
  src="imagenes/foto.jpg"
  alt="Foto del equipo de trabajo"
  width="400"
  height="300"
>

<!-- Imagen externa (URL) -->
<img
  src="https://picsum.photos/400/300"
  alt="Imagen de ejemplo"
>

<!-- Imagen con enlace -->
<a href="index.html">
  <img src="logo.png" alt="Logo — regresar al inicio">
</a>
💡 Organización de archivos

Guarda tus imágenes en una subcarpeta llamada imagenes/ dentro de tu proyecto. Así el código src="imagenes/foto.jpg" siempre la encontrará.

09

HTML Semántico

HTML5 introdujo etiquetas con significado propio que reemplazan el uso excesivo de <div>. Esto mejora la accesibilidad, el SEO y la legibilidad del código.

Etiqueta
Cuándo usarla
<header>
Encabezado de la página o de una sección. Suele contener el logo y la navegación.
<nav>
Bloque de enlaces de navegación principal.
<main>
Contenido principal único de la página. Solo debe haber uno por página.
<section>
Sección temática de contenido. Suele tener su propio encabezado.
<article>
Contenido independiente y reutilizable: blog post, noticia, tarjeta.
<aside>
Contenido secundario o complementario. Barras laterales, widgets.
<footer>
Pie de página con información de contacto, copyright, enlaces.
💡 Regla práctica

Antes de usar <div>, pregúntate: ¿existe una etiqueta semántica para esto? Si la respuesta es sí, úsala. Los <div> son para agrupar sin significado específico.

10

Construyendo el Layout de Página

Ahora combinamos todo lo aprendido. Una página web típica tiene esta estructura semántica:

HTML — Estructura de Página Completa
<body>

  <!-- ① Encabezado con navegación -->
  <header>
    <a href="index.html">
      <img src="logo.png" alt="Mi Sitio">
    </a>
    <nav>
      <ul>
        <li><a href="#inicio">Inicio</a></li>
        <li><a href="#sobre-mi">Sobre Mí</a></li>
        <li><a href="#proyectos">Proyectos</a></li>
        <li><a href="#contacto">Contacto</a></li>
      </ul>
    </nav>
  </header>

  <!-- ② Contenido principal -->
  <main>

    <!-- Hero / Portada -->
    <section id="inicio">
      <h1>Hola, soy Ana García</h1>
      <p>Diseñadora y desarrolladora web.</p>
      <a href="#proyectos">Ver mis proyectos</a>
    </section>

    <!-- Sobre Mí -->
    <section id="sobre-mi">
      <h2>Sobre Mí</h2>
      <img src="imagenes/perfil.jpg" alt="Foto de Ana">
      <p>Me apasiona crear experiencias web...</p>
    </section>

    <!-- Proyectos -->
    <section id="proyectos">
      <h2>Proyectos</h2>
      <article>
        <h3>Proyecto 1</h3>
        <img src="imagenes/proyecto1.jpg" alt="Captura del proyecto">
        <p>Descripción breve del proyecto.</p>
        <a href="https://github.com/ana">Ver código</a>
      </article>
    </section>

    <!-- Contacto -->
    <section id="contacto">
      <h2>Contacto</h2>
      <p>Escríbeme a
        <a href="mailto:ana@ejemplo.com">
          ana@ejemplo.com
        </a>
      </p>
    </section>

  </main>

  <!-- ③ Pie de página -->
  <footer>
    <p>&copy; 2025 Ana García. Todos los derechos reservados.</p>
  </footer>

</body>

¡Este es tu punto de partida! A partir de aquí, con CSS3 puedes transformar completamente el aspecto visual: colores, fuentes, espaciado, columnas, animaciones y mucho más.

Checklist de tu primer sitio

  • Archivo index.html creado con la estructura base completa
  • Etiqueta <header> con logo y navegación usando anclas
  • Sección <main> con al menos 3 secciones identificadas con id
  • Imágenes con atributo alt descriptivo en todas
  • Etiqueta <footer> con información de copyright
  • Todos los enlaces de navegación apuntando a sus secciones con #id
  • HTML válido: todas las etiquetas correctamente cerradas
